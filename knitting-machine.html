Knitting Machine

An automated knitting machine that lets users set the required knitting length and produces knitted fabric with controlled length and speed.

Product prototype

How it works

  1. 01

    The user loads the knitting thread into the machine.

  2. 02

    The user sets the required knitting length in inches using the control switches.

  3. 03

    The user selects the desired knitting speed.

  4. 04

    The machine automatically performs the knitting operation according to the selected length and speed.

  5. 05

    The machine stops automatically when the set knitting length is reached.

What it is

An Automated Knitting Machine designed to produce knitted fabric using knitting thread with controlled length and speed.

Key features

Automatic knitting operation

Adjustable knitting length in inches

User-controlled knitting speed

Simple switch-based operation

Compact design with an acrylic enclosure

Consistent and convenient fabric production
