Movable Shooting Game

The Interactive Arcade Shooting Game is an electronic gaming system designed to deliver an engaging target-shooting experience through real-time target interaction and automated score tracking

Product prototype

How it works

4 steps · tap a step or press play

  1. 01

    The player uses the toy gun to aim at the moving targets.

  2. 02

    The player shoots at the targets to score points.

  3. 03

    When a target is hit, the system instantly updates and displays the score on the screen.

  4. 04

    Players can track their progress throughout the game and reset the score to start a new round

What it is

The system features moving targets that players aim at and shoot using a toy gun. When a target is successfully hit, the system detects the interaction, updates the player's score, and displays the result on a screen.

Key features

Moving targets for an interactive shooting experience

Real-time score calculation and display

Easy-to-use controls for a smooth gaming experience

Convenient reset function for repeated gameplay

Where it's used
