Rehabilitation Peg Board

The Rehabilitation Peg Board guides patients to place pegs in set positions using visual indicators, with color-coded feedback on right and wrong placements.

Product prototype

How it works

4 steps · tap a step or press play

  1. 01

    A visual indicator lights up the target hole.

  2. 02

    The patient picks up a peg and places it.

  3. 03

    Color-coded feedback shows whether the placement was correct or incorrect.

  4. 04

    The next target lights up and the exercise continues.

What it is

An interactive version of the classic therapy peg board. Lights show where each peg should go and confirm whether it was placed correctly.

Key features

Visual guidance for each placement

Color-coded correct/incorrect feedback

Easy-to-follow exercise flow

Where it's used

Physiotherapy Occupational therapy Hand rehabilitation Motor-skill training

Benefits

  • Improves hand-eye coordination and fine motor skills
  • Builds accuracy through instant feedback
  • Adds cognitive engagement to hand therapy
