Solar System Model

An educational solar system model that identifies a planet placed on it and tells users about that planet through audio narration.

Product prototype

How it works

  1. 01

    The user selects and places a planet in its designated position on the solar system model.

  2. 02

    The device detects the selected planet using magnetic sensing.

  3. 03

    The system identifies the planet and retrieves its corresponding information.

  4. 04

    The information about the planet is played through a speaker as an audio explanation.

What it is

A Solar System is an educational device designed to teach users about the planets and our solar system through hands-on interaction. Users can place a planet on the model, and the device automatically identifies it and provides information about that planet through audio narration.

Key features

Interactive planet identification

Automatic planet detection

Audio-based-educational explanations

Simple, user-friendly operation

Hands-on learning experience
