Moveable Chatbot

The Moveable Chatbot is a mobile interactive robot designed to communicate with users and move between locations. It can combine a conversational interface with a motorized platform to provide an engaging and helpful robotic companion.

Product prototype

How it works

  1. 01

    The user interacts with the chatbot using the available input method.

  2. 02

    The controller processes the command and produces a response through audio, a display or another output.

  3. 03

    The drive system moves the robot when a movement command is received, while sensors may help it avoid obstacles.

What it is

A mobile robot that can respond to user inputs through voice, text or programmed commands. Its movement and interaction features depend on the sensors, controller and software integrated into the prototype.

Key features

Mobile robotic platform

Voice or command-based interaction, depending on configuration

Audio or display-based responses

Where it's used

Educational demonstrations Reception areas Exhibitions Interactive learning Personal-assistant prototypes

Benefits

  • Makes human-robot interaction more engaging
  • Can support learning and demonstrations
  • Combines mobility with conversational interaction
  • Can be adapted for different assistance tasks
