Smart Napkin Vending Machine

The Smart Napkin Vending Machine provides napkins when a user presses a button and keeps track of the available quantity. It updates stock details over a Wi-Fi network after every dispensing action and indicates when the stock is low.

Product prototype

How it works

  1. 01

    The user presses the button to dispense a napkin.

  2. 02

    The machine releases a napkin and checks whether it has been dispensed successfully.

  3. 03

    The available quantity is updated over the Wi-Fi network after each dispensing action.

What it is

A simple napkin dispensing machine that allows users to collect napkins by pressing a button. It keeps track of the remaining quantity and shares stock updates over a Wi-Fi network, making it easier to monitor and refill the machine when needed.

Key features

Button-operated napkin dispensing

Automatic tracking of available napkins

Wi-Fi stock updates after every dispensing action

Where it's used

Schools Colleges Hospitals Offices Shopping malls Public facilities

Benefits

  • Provides easy access to napkins
  • Helps monitor the available stock
  • Reduces the need for frequent manual stock checking
  • Indicates when the stock is low
  • Makes restocking and stock management easier
